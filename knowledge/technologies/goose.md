# Goose (programming language)

New experimental memory-safe systems language by Wouter van Oortmerssen
(creator of Lobster). Apache-2.0. Compiles whole programs to one C file
(runs in-process via TinyCC, or native via a system C compiler). Repository
produced "almost entirely with AI, from a human language design" per the
author. Repo appears to date from August 2026 (secondary source, verify).

Status as of 2026-10-25: no independent review or audit found; benchmark
claims (16 benchmarks, ~1.12x best safe Rust) are the author's own, and the
page's intro and table figures differ. Re-check before citing.

Primary source: https://aardappel.github.io/goose/
See `memory-safety-models.md` for comparison with Rust and Zig.
