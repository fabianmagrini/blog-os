# UI SDK (vercel-labs/ui)

Headless behaviors library for agents building UI: `@ui-sdk/core` plus
adapters (React, Vue, Svelte, Solid, Web Components), 55 unstyled React
components, an agent skill (`npx skills add vercel-labs/ui --skill ui-sdk`).
Also a runtime bridge: `createAgent` (`snapshot`/`act`/`query`) and WebMCP
(`document.modelContext`) with `allow`, `data-agent-confirm`,
`data-agent-hidden`, `data-agent-secret`; docs admit `allow` checks actions
only. Apache-2.0, 4.6k stars, 0.1.0-beta.2 (all pre-release). Does not mention
A2UI/AG-UI/"generative UI". Sources: https://github.com/vercel-labs/ui ,
https://ui-sdk.dev/docs/agents .
