# BAML (new language, canary)

BoundaryML. Apache-2.0. Typed functions that call models (`client` + `prompt`,
`ctx.output_format()`), typed errors (`throws`, `catch`, exhaustive
`catch_all`), `spawn`/`await` concurrency, TypeScript bridge generating
`baml_sdk/`, `baml run/check/test`. Docs say to install Canary; as of
2026-11-07 the catalog states "No stable release has been published"; v0.25.2
canary published 2026-11-06. Book partially published (testing, evals,
classes, prompts chapters not yet). Older BAML (v0) documented separately and
claims production use; relationship unexplained.

Sources: https://developer.boundaryml.com/baml , https://developer.boundaryml.com/cli
