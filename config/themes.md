# Themes

`blog-os` initially focuses on long-form technical writing within these
themes. Signals, ideas, and articles should generally connect to at least one.

- AI-native software engineering
- software architecture
- agentic engineering
- developer platforms
- developer productivity
- AI-native SDLC
- software factories
- platform engineering
- engineering operating models
- developer experience
- frontend architecture
- enterprise architecture
- agent harnesses
- engineering leadership
- emerging developer tools
- cloud architecture
- system design

## Using this list

- The Scout agent should tag each signal with one or more of these themes
  (`themes:` in `templates/signal.yaml`).
- A signal or idea that fits none of these themes is not automatically
  disqualified, but it should be flagged as off-theme so the human reviewer
  makes the call explicitly rather than the backlog drifting by default.
- This list should evolve. If a theme keeps producing signals nobody ever
  shortlists, or if published articles keep clustering around a theme that
  is not listed here, update this file and note why in the relevant
  retrospective (`agents/retrospective.md`).
